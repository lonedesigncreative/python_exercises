> # CODE EXPLANATION:
> 
> 1. `integer_number = 25`
> - Integer variable (int), which is a whole number without a decimal point
> 
> 2. `decimal_number = 3.14`  
> - Decimal variable (float), which is a number that can have a fractional part (decimal point). In this case, it contains the value 3.14, which is an approximation of the mathematical constant pi.
>
> 3. `text_example = "Hello, world!"` 
> - Text variable (string), which is a sequence of characters enclosed in quotes. In this case, it contains the text "Hello, world!" that will be stored in the variable text_example.
> 
> 4. `print("The integer value is:", integer_number)` 
> - Shows the integer value, which will output "The integer value is: 25" to the console, combining the text with the value of the integer_number variable.
> 
> 5. `print("The decimal value is:", decimal_number)`
> - Shows the decimal value, which will output "The decimal value is: 3.14" to the console, combining the text with the value of the decimal_number variable.
> 
> 6. `print("The stored text is:", text_example)`
> - Shows the text, which will output "The stored text is: Hello, world!" to the console, combining the text with the value of the text_example variable.
