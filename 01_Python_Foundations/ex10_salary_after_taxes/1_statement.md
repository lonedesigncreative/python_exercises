# Exercise description:

- Create a program that **asks the user to enter their gross salary (before any deductions)**.
- The program should then *calculate the Social Security deduction*, set at **6.2%**, and the *Federal Income Tax deduction*, set at **12%**.
- After performing the calculations, the program must **display the amount deducted for Social Security**, the **amount deducted for Federal Tax**, and finally the **net salary after all deductions**.
