> # CODE EXPLANATION:
> 
> 1. `number = int(input("Enter an integer number: "))`
> - Reads a value from the user as text with `input()` and immediately converts it to an integer using `int()`, storing it in the variable `number`.
> 
> 2. `double_value = 2 * number`  
> - Multiplies the value stored in `number` by `2` and stores the result in the variable `double_value`.
>
> 3. `print(f"The double of {number} is: {double_value}")` 
> - Prints a formatted string showing the original `number` and its double, inserting the values of number and `double_value` into the message.
