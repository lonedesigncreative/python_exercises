# Exercise description:

- The program must:
    - Receive the values of the **legs** `a` and `b`.
    - Compute the hypotenuse using the Pythagorean theorem:
      - $$h = \sqrt{a^2 + b^2}$$

      - Where:
        - **a** and **b** = the legs (catheti) of the triangle
        - **h** = the hypotenuse

    - Display the value of the hypotenuse.

- This exercise practices **powers**, **square roots**, and **math functions**.
