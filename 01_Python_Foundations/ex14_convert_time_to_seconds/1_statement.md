# Exercise description:

- The program must:
    - Receive three integer values: **hours**, **minutes**, and **seconds**.
    - Convert everything into total seconds using:
      - 1 hour = 3600 seconds
      - 1 mimute = 60 seconds

      - $$\text{total_seconds} = (h \cdot 3600) + (m \cdot 60) + s$$
        - Where:
            - **h** = hours
            - **m** = minutes
            - **s** = seconds

    - Add all values and display the total number of seconds.

- This exercise helps practice **arithmetic operations**, **multiple parameters**, and **unit conversions**.
