## 📘 What Do These Exercises Present? - Python Foundations

This worksheet provides a practical introduction to the **fundamentals of Python programming**, aimed at beginners in Information Management and Data Science.

### 🔹 Fundamental Concepts
- **Variables and Data Types**  
  - Declaring integers, floats, and strings  
  - Naming rules (no starting numbers, no spaces, no reserved keywords)  
  - Basic types: **int**, **float**, **str**

- **Comments**  
  - Using `#` to document code

### 🔹 Essential Functions
- **Input & Output**  
  - `print()` — display messages and values  
  - `input()` — read user input  

- **Type Conversion**  
  - `int()` — convert text to integer  
  - `float()` — convert text to decimal  

### 🔹 Arithmetic Operators
- `+` addition  
- `-` subtraction  
- `*` multiplication  
- `/` division  
- `%` modulus (remainder)  
- Parentheses define operation priority  

### 🔹 Practical Applications in the Exercises
- Simple calculations (triangle area, land price)  
- User data processing (name, age, grades)  
- Financial calculations (salary deductions, VAT, monthly salary)  
- Basic menu creation (simple text interface)

### ✅ Summary
This worksheet introduces the **core building blocks of Python**: variables, data types, operators, input/output, and simple problem‑solving — forming the foundation for all later topics.
