## 📘 What Do These Exercises Present? - Decision Structures

This worksheet introduces the fundamentals of **decision structures in Python**, teaching how programs make choices based on conditions.

### 🔹 Core Concepts
- **Conditional Statements**
  - `if` — simple decision  
  - `if / else` — dual decision  
  - `if / elif / else` — selective decision  
  - Nested and chained conditions  

- **Logical Operators**
  - `and` — both conditions must be true  
  - `or` — at least one condition must be true  
  - `==`, `!=`, `>`, `<`, `>=`, `<=` — comparison operators  

- **Input Validation**
  - Checking if values are within valid ranges  
  - Displaying error messages when conditions fail  

### 🔹 Practical Applications in the Exercises
- Age verification (major/minor)
- Number comparisons (greater, equal, between ranges)
- Safe division (prevent division by zero)
- Car fuel consumption calculation with validation
- Even/odd number detection using `%`
- Finding the largest of three numbers
- Converting numeric grades to text labels
- Building a simple calculator using operators
- Determining the number of days in a month
- Creating a menu with selectable options and validation

### ✅ Summary
This worksheet teaches how to use **conditional logic** to control program flow, validate user input, and build interactive decision‑based applications — forming the foundation for more complex logic in future exercises.
