# Exercise description:

- Ask the user to enter an **integer value between 1 and 12**, representing a month of the year.
- After reading the input, the program must **validate the value**, ensuring it falls within the allowed range.
- Then, using a **selective decision structure**, determine how many days the selected month contains.
- Months with **30 days** should be identified accordingly.
- Months with **31 days** should also be indicated.
- For **month 2 (February)**, the program must state that it has **28 or 29 days**, depending on the year.
