# Exercise description:

- Display a **menu of options** related to customer management.
- The menu should include the following actions:
-   1. Add Customer
-   2. Edit Customer
-   3. Delete Customer
-   4. Exit the program
- After showing the menu, the program must **ask the user to choose an option**.
- Once the user makes a selection, the program should **display the chosen option**, for example:
  - *“You selected option number 3.”*
- If the user enters a value that does not correspond to any of the available options, the program must show the message **“Invalid option.”**
