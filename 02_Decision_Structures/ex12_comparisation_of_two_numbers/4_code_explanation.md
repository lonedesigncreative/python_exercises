> # CODE EXPLANATION:
> 
> 1. `n1 = float(input("Enter the first number: "))`
> - Reads a value from the user as text, converts it to a floating‑point number, and stores it in `n1`.
> 
> 2. `n2 = float(input("Enter the second number: "))`  
> - Reads another value from the user, converts it to a floating‑point number, and stores it in `n2`.
> 
> 3. `if n1 == n2:` 
> - Checks whether the value in n1 is exactly equal to the value in `n2`.
>
> 4. `print("The numbers are equal.")`
> - If the condition is true, prints a message saying the numbers are equal.
> 
> 5. `else:`  
> - Defines the alternative path when `n1` is not equal to `n2`.
> 
> 6. `print("The numbers are different.")` 
> - Prints a message saying the numbers are different.
