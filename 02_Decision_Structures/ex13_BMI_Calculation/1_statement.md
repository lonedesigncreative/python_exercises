# Exercise description:

- Create a program that:
  - Requests the user’s **name**, **age**, **weight**, and **height**.
  - Calculates the **Body Mass Index (BMI)** using the formula:
        - $$IMC = \frac{\text{peso}}{\text{altura}^2}$$
  - Displays the calculated BMI value.
  - Classifies the BMI according to the following categories:
        - BMI < 17 → **Very underweigh**t
        - 17 ≤ BMI < 18.5 → **Underweight**
        - 18.5 ≤ BMI < 25 → **Normal weight**
        - 25 ≤ BMI < 30 → **Overweight**
        - 30 ≤ BMI < 35 → **Obesity I**
        - 35 ≤ BMI < 40 → **Obesity II (severe)**
        - BMI ≥ 40 → **Obesity III (morbid)**
