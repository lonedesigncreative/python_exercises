## 📘 What Do These Exercises Present? - Loops & Random Numbers

This worksheet introduces the fundamentals of **repetition structures (loops)** in Python, along with the basics of generating random numbers.

### 🔹 Core Concepts
- **For Loops (automatic counter)**
  - Iterating through sequences using `for`
  - Using `range(start, end)` to generate number sequences
  - Looping with fixed repetition counts

- **While Loops (manual counter)**
  - Repeating actions while a condition remains true
  - Manual incrementing and stopping conditions
  - Using `break` to exit loops

- **Random Number Generation**
  - Importing the `random` module
  - Using `random.randint(min, max)` to generate integers

### 🔹 Practical Applications in the Exercises
- Summing all even numbers between 1 and 50  
- Generating a multiplication table using loops  
- Calculating the average of user‑entered values  
- Summing numbers with a `while` loop  
- Repeating input until the user enters `0`  
- Building a **number guessing game** using loops + random numbers  
- Creating a **repetitive menu system** with validation and loop control

### 🔹 Additional Skills Practiced
- Input handling inside loops  
- Conditional checks inside loops  
- Combining loops with decision structures  
- Designing interactive console programs  

### ✅ Summary
This worksheet teaches how to use **for** and **while** loops to repeat actions, process sequences, validate input, and build interactive programs — including the first game (Guess the Number). It also introduces the `random` module, expanding Python’s capabilities for dynamic and unpredictable behavior.
