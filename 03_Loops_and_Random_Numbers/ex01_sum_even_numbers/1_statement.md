# Exercise description:

- Create a program that uses a **repetition structure with an automatic counter (`for` loop)** to iterate through all values in the interval from **1 to 50** (inclusive).
- During the loop, the program must **identify all even numbers** and add them to an accumulating total.
- After completing the iteration, the program should **display the final sum** of all even numbers found within the interval.
- To generate the sequence automatically, the program must use the `range()` **function**, specifying both the **minimum** and **maximum** limits of the interval.
