# Exercise description:

- Create a program that randomly **generates an integer between 1 and 10**, using a random number generation library.
- Then, build a **repetition structure** that allows the user to try to guess the generated number.
- On each attempt, the program should **read the user’s guess** and check whether it matches the secret number.
- If the user guesses correctly, the program must display a **success message**.
- If the guess is incorrect, the program should **inform the user that the attempt was wrong** and request another guess.
- This process must continue a**s many times as necessary**, until the user finally guesses the correct number.
