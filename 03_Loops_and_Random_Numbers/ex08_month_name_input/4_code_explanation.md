> # CODE EXPLANATION:
> 
> 1. `number = int(input("Enter the month number (1 - 12): "))`
> - Reads what the user types as text, converts it to an integer, and stores it in `number`.
>
> 2. `match number:`
> - Starts a match block to compare the value of number against several cases.
>

> `print("January")`
