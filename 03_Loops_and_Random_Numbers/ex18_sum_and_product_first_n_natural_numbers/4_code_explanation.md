> # CODE EXPLANATION:
> 
> 1. `N = int(input("Enter N: "))`
> - Reads an integer from the user and stores it in `N`.
>
> 2. `total = 0`
> - Initializes `total` to `0` for the sum.
>
> 3. `product = 1`
> - Initializes `product` to `1` for the product.
>
> 4. `for i in range(1, N + 1):`
> - Starts a loop with `i` from `1` to `N`.
>
> 5. `total += i`
> - Adds `i` to `total`.
>
> 6. `product *= i`
> - Multiplies product by `i` and stores the result back in `product`.
>
> 7. `print(f"Sum = {total}")`
> - Prints the final sum.
>
> 8. `product = 1`
> - Initializes `product` to `1` for the product.
>
> 9. `print(f"Product = {product}")`
> - Prints the final product.
