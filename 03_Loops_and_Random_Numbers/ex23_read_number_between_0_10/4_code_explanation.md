> # CODE EXPLANATION:
> 
> 1. `while True:`
> - Starts an infinite loop that will only stop when a `break` is executed.
>
> 2. `number = int(input("Enter a number between 0 and 10: "))`
> - Reads an integer from the user and stores it in `number`.
>
> 3. `if 0 <= number <= 10:`
> - Checks if `number` is between `0` and `10` (inclusive).
>
> 4. `print("Valid number.")`
> - If the condition is true, prints `"Valid number."`.
> 
> 5. `else:`
> - Runs if `number` is outside the range 0–10.
>
> 6. `print("Number out of range. Program ended.")`
> - Prints a message saying the number is out of range and the program is ending.
>
> 7. `break`
> - Exits the `while` loop, ending the program.
