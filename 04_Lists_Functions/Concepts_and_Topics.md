## 📘 What Do These Exercises Present? - Lists, Dictionaries & Functions

This worksheet introduces the fundamentals of **data structures (lists and dictionaries)** and **subprograms (functions)** in Python. It expands the learner’s ability to store, manipulate, and process collections of data.

---

### 🔹 Core Concepts — Lists
- Creating lists (`[]`)
- Adding elements  
  - `append()` — add at the end  
  - `insert()` — add at a specific index  
- Modifying elements by index  
- Removing elements  
  - `pop()` — remove by index  
- Counting elements  
  - `len()`  
- Iterating through lists with `for`  
- Using `enumerate()` to get index + value  
- Sorting lists with `sort()`  
- Accessing elements using negative indexing (e.g., `list[-2]`)

---

### 🔹 Core Concepts — Data Analysis with Lists
Using built‑in functions to analyze numeric lists:

- `max()` — highest value  
- `min()` — lowest value  
- `sum()` — total of all values  
- `len()` — number of elements  
- `statistics.mean()` — average  

These are applied to real datasets such as temperatures and monthly expenses.

---

### 🔹 Core Concepts — Dictionaries (Introduced Indirectly)
Although not the main focus, the worksheet prepares the student for structured data handling, which is expanded in later fichas.

---

### 🔹 Core Concepts — Functions (Subprograms)
The worksheet introduces how to create and use functions:

- Defining functions with `def`
- Passing parameters  
- Printing results inside the function  
- Returning values to the main program  
- Using functions for:
  - Showing name and age  
  - Summing numbers  
  - Calculating triangle area  
  - Calculating average of grades  
  - Validating bank balance  
  - Checking if an email ends with a specific domain (`endswith()`)

---

### 🔹 Practical Applications in the Exercises
- Manipulating numeric and text lists  
- Analyzing expenses and temperatures  
- Finding longest/shortest words  
- Finding the second largest number  
- Validating numeric input ranges  
- Building a list of grades with constraints  
- Creating reusable functions for calculations  
- Email validation using string methods  

---

### ✅ Summary
This worksheet teaches how to work with **lists**, **loops**, **data analysis functions**, and **user‑defined functions**, enabling the creation of more structured, reusable, and scalable Python programs. It is a key step from basic programming toward real‑world data processing.
