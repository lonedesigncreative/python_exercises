# Exercise description:

- Add **four integer values** to the list using the **append** function.
- Insert **one new element** between index 1 and index 2 using the **insert** function.
- Replace the value at **index 2** with a number of your choice.
- Remove the element at **index 1** using the **pop** function.
- Display how many elements the list contains using the len function.
- Loop through the list using a **for loop** and print both the index and the value during each iteration.
- Repeat the previous task, but this time use the **enumerate** function to automatically generate a counter while iterating through the list.
