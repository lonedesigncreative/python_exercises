# Exercise description:

- Create a program that defines a list variable named cidades (cities). Then complete the following tasks:

1. **Add new elements:**  
      - Insert **four text values** (city names) into the list using the **append** function.

2. **Insert an element at a specific position:**  
      - Add **one new city** between indices **2** and **3** using the **insert** function.

3. **Modify an existing value:**  
      - Replace the value stored at index 1 with a new text value of your choice.

4. **Remove an element by index:**  
      - Delete the element located at **index 3** using the **pop** function.

5. **Count the elements in the list:**  
      - Display the **total number of items** in the list using the **len** function.

6. **Iterate through the list using a FOR loop:**  
      - Use a **for loop** to go through each element in the list, printing both the **index** and the value during each iteration.

7. **Use the enumerate() function:**  
      - Repeat the previous task, but this time use the **enumerate** function to automatically generate a counter while iterating through the list.
