# Exercise description:

- In this exercise, you are given a list of numerical temperature readings collected at different moments throughout the day:
  - **temperatures = [18.5, 20.0, 19.3, 21.7, 22.1, 17.8, 16.9, 23.4, 24.0, 19.8]**
- Your task is to create a Python program that analyses this data using simple built‑in statistical functions. Specifically, you should:
    - Use the **max** function to determine the **highest temperature** in the list.
    - Use the **min** function to identify the **lowest temperature** recorded.
    - Apply the **sum** function to calculate the **total of all temperature values**.
    - Use the **len** function to find out **how many temperature readings** are stored in the list.
    - Import the `statistics` module and use the **mean** function to compute the **average temperature**.
