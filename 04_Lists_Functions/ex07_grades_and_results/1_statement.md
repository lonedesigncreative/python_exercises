# Exercise description:

- In this exercise, you will create a Python program that works with a list named notas. The program must allow the user to enter numeric values and, at the end, display several statistical results.
- The program should follow these steps:
  - Use a **loop structure** to repeatedly ask the user to enter numerical values.
  - Each valid value must be **added to the `notes` list**.
  - The loop must only stop when the user enters the number **0**.
  - The program must **only accept decimal numbers between 1 and 20**; any value outside this range should be rejected with an appropriate message.
  - At the end, the program must display:
      - the **highest value** entered
      - the **lowest value**
      - the **average** of all values
      - the **total number of values** stored in the list
