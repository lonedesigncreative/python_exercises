# Exercise description:

## Basic Operations with a List of Colors

- Consider the list:
- `colors = ["yellow", "blue", "white", "black", "green"]`

-Write a program that:
  - Prints **all elements** of the list.
  - Prints the element at **index 2**.
  - Replaces the element at **index 0 **with `"red"`.
  - Prints the **updated list**.
  - Adds `"yellow"` to the **end** of the list.
  - Prints the list again.
  - Inserts `"purple"` at **index 2**.
  - Prints the updated list.
  - Removes the **last element** of the list.
  - Prints the list again.
  - Prints the **size** of the list using `len()`.
