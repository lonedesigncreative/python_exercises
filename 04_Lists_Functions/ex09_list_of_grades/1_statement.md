# Exercise description:

## Working with a List of Grades

- Consider the list:
- `grades = [11.2, 15, 8.7, 17.2, 7.9]`

- Write a program that:
  - Adds the value `10.9` to the **end** of the list and prints the full list.
  - Prints the **number of elements** in the list.
  - Prints the **minimum value** in the list.
  - Calculates and prints the **average** of all values.
