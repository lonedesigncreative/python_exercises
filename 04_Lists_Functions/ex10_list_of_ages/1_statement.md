# Exercise description:

## Processing a List of Ages

- Consider the list:
`ages = [25, 15, 19, 22, 37, 78, 46, 2, 67]`

- Write a program that:
- Counts how many people are **under 18**.
- Sorts the list in **descending order**.
- Asks the user for an age and checks whether it **exists in the list**:
- If it exists → print `"The age is in the list"`.
- Otherwise → print `"There is no one with that age in the list"`.
