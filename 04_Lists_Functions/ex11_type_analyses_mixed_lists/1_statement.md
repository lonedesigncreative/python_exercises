# Exercise description:

## Type Analysis in a Mixed List

- Consider the list:
- `nums = [10, 2.5, 7, 11, 7.9, "Python", True, 6, 5.8, "Lists"]`

- Write a program that:
  - Counts and prints how many **integers**, **floats**, **strings**, and **booleans** are in the list.
  - Calculates the **average** of all **integer values**.
  - Creates and returns a **new list** containing only the **integers**.
