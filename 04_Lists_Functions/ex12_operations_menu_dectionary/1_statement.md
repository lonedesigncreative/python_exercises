# Exercise description:

## Operations on a Menu Dictionary

- Consider the dictionary:
- `menu = {`
-    `"Pork Belly": 7,`
-    `"Sardine": 6,`
-    `"Filets": 5.5,`
-    `"Steak Sandwich": 7,`
-    `"Hamburger": 5.5`
- `}`
- Write a program that:
  - Prints the **price** of `"Steak Sandwich"`.
  - Prints all **keys** (dish names) in the dictionary.
  - Adds `"Omelette"` with the price `5`.
  - Prints the **entire dictionary** after the update.
