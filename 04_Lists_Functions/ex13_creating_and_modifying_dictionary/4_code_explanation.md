> # CODE EXPLANATION:
> 
> 1. `person = {"name": "Ana", "age": 30}`
> - Creates a dictionary named `person` with two key–value pairs.
> 
> 2. `print(person)`
> - Prints the `person` dictionary.
> 
> 3. `person["city"] = "New York"` 
> - Adds a new key `"city"` with value `"New York"` to the dictionary.
> 
> 4. `person["job"] = "Designer"` 
> - Adds another key `"job"` with value `"Designer"`.
>
> 5. `person.pop("age")` 
> - Removes the key `"age"` and its value from the dictionary.
> 
> 6. `print(person.keys())` 
> - Retrieves and prints all the keys in the `person` dictionary.
