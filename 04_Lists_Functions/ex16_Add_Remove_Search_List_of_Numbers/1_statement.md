## Add, Remove and Search in a List of Numbers

- Use essential list methods to manage numeric data:
  - `append()` → add a single element.
  - `extend()` → add multiple elements.
  - `remove()` → remove the first occurrence of a value.
  - `pop()` → remove an element by index.
  - `index()` → find the position of a value in the list.
