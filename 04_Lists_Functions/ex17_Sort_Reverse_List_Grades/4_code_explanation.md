> # CODE EXPLANATION:
> 
> 1. `grades = [14, 8, 17, 12, 9, 18, 11, 16, 7, 13]`
> - Creates a list named `grades` with ten integers.
> 
> 2. `sorted_grades = sorted(grades)`
> - Creates a new sorted list and stores it in `sorted_grades`.
> 
> 3. `grades.sort()` 
> - Sorts the original list in ascending order.
> 
> 4. `grades.sort(reverse=True)` 
> - Sorts the original list in descending order.
>
> 5. `grades.reverse()`
> - Reverses the order of the elements in the list.
> 
> 6. `print("Sorted copy:", sorted_grades)`
> - Prints the sorted copy created earlier.
> 
> 7. `print("Descending:", grades)` 
> - Prints the modified list in descending order.
