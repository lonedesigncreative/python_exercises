# Exercise description:

## Weekly Temperature Log

- Create a list with the maximum temperatures of 7 consecutive days and:
  - Print the **highest** temperature of the week.
  - Print the **lowest** temperature.
  - Calculate and print the **average** temperature.
  - Print the **days (indices)** where the temperature was **above average**.
- Functions to use: `max()`, `min()`, `sum()`, `len()`.
