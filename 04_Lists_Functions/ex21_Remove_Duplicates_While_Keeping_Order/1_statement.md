# Exercise description:

## Reverse a List Without Using reverse()

- Create a function `invert(lst)` that:
    - Receives a list of numbers.
    - Returns a **new list** with the elements in reverse order.
    - Does **not** use `lst.reverse()` or slicing `[::-1]`.
    - Uses a for loop and either `insert()` or `append()`.

Test with:
    - `[1, 2, 3, 4, 5]`
    - `['a', 'b', 'c']`
