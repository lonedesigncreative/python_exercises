- In this exercise, you must create a Python program that includes a function named `Calculate_Balance`.
- The function should receive **two input parameters**: the current balance and the **amount to withdraw**.

- Inside the function, you must calculate the **difference between the balance and the withdrawal amount**.

- If the result is negative, the program must display the message:
> - “You cannot withdraw an amount that results in a negative balance”

- Otherwise, the program should show the final balance after the operation.
