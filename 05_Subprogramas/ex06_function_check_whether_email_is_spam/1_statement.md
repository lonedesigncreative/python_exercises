- In this exercise, you must create a Python program that includes a function named `Check_Email`.
- The function should receive **one input parameter**, which corresponds to the **email provided by the user**.

- Inside the function, you must use a **dual decision structure**, applying the `endswith()` method to check whether the email ends with the expression **"@xpto.pt"**.
    - If the email does end with this expression, the program should display a message indicating that the email is spam.
    - Otherwise, it should display a message stating that the email is not spam.
