# Exercise description:

## Remove Duplicates While Keeping Order

- Given a list of 10 grades (0 to 20), create a program that:
  - Sorts the list in **descending order**.
  - Prints the **top 3 grades** using slicing.
  - Prints how many students scored below 10 (failed).

- Functions to use:
  - `sort(reverse=True)`
  - `len()`
  - list comprehension.
